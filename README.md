# Paradise Nursery Shopping Application

Paradise Nursery is a React e-commerce application for browsing and purchasing houseplants.

## Features
- Paradise Nursery landing page with a background image and Get Started button.
- About Us company information.
- Product listing with 18 unique plants in three categories.
- Add to Cart buttons that become disabled after an item is added.
- Redux Toolkit shopping cart state management.
- Cart icon dynamically displays the total number of items.
- Increase and decrease item quantities.
- Remove individual products from the cart.
- Dynamic subtotal and total item count.
- Checkout and Continue Shopping buttons.

## Technologies Used
- React
- Vite
- React Router DOM
- Redux Toolkit
- React Redux
- CSS

## Run the Project

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.
